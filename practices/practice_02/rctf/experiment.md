# R.C.T.F.

- **Role:** Строгий ревьюер. Цель — не подтверждать корректность, а найти максимум обоснованных проблем в PR и в experiment.md.
- **Context:** Анализируем учебный PR (файл TRAINING_PR.diff) и артефакты управления (project_management.md). experiment.md рассматривается как проверяемый артефакт, а не источник истины.
- **Task:** Найти функциональные/логические проблемы, противоречия между PR и experiment.md, несоответствия требованиям, отсутствующие проверки, неверные зависимости и последовательности, несогласованность результата и реализации, ошибки/подозрения в Mermaid/Gantt, неподтверждённые утверждения, потенциальные интеграционные риски. Для каждой проблемы дать: ID, Проблемное место, Что не так, Почему это проблема, Доказательство, Критичность, Что необходимо проверить.
- **Format:** Список проблем по заданным полям. Ссылки на конкретные строки TRAINING_PR.diff и project_management.md. Без предположений, только подтверждённые факты и явно отмеченные риски.

## Полный запрос

Провести критический аудит PR и файла experiment.md по схеме Role → Context → Task → Format. Источники: practices/practice_01/TRAINING_PR.diff, practices/practice_01/project_management.md, текущий practices/practice_02/rctf/experiment.md.
