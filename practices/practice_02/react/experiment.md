## Найденные проблемы и риски

Подтверждённые (с классом):

1. CRITICAL — Отсутствие валидации входа и некорректный код ответа при отсутствии поля diff.
   - Evidence: TRAINING_PR.diff app/api.py:35–38 — доступ к payload["diff"] без проверки приводит к KeyError → 500.
   - Сравнение: заявлено (Inc 1) 422 при отсутствии diff → изменено — нет проверки → проверено по diff.

2. HIGH — Отсутствует ограничение длины diff (API-1), возможен перегруз и отсутствие 413.
   - Evidence: TRAINING_PR.diff app/api.py:35–38 — отсутствует проверка длины; в review_service нет усечения.
   - Сравнение: заявлено лимит 20 000 → изменено — нет проверки → проверено по diff.

3. HIGH — Секреты не редактируются перед отправкой в LLM (SEC-1), риск утечки.
   - Evidence: TRAINING_PR.diff app/review_service.py:19–22 — diff конкатенируется в prompt без редактирования.
   - Сравнение: заявлено очистка секретов → изменено — прямой pass-through → проверено по diff.

4. HIGH — Нет timeout и контролируемой ошибки при вызове LLM (REL-1); падение сервиса при исключениях.
   - Evidence: TRAINING_PR.diff app/review_service.py:19–22 — прямой вызов llm.generate без таймаута/обработки.
   - Сравнение: заявлено timeout 10s и graceful error → изменено — отсутствует → проверено по diff.

5. MEDIUM — Ответ не соответствует OUT-1 (структура), возвращается {"comment": str} без summary/risks/checks.
   - Evidence: TRAINING_PR.diff app/review_service.py:22; app/api.py:36–38.
   - Сравнение: заявлено OUT-1 → изменено — плоский comment → проверено по diff.

6. LOW — Отсутствует наблюдаемость по OBS-1 (нет логов request_id/длительности/статуса, но и утечки логов нет).
   - Evidence: По diff отсутствует логирование в затронутых файлах.
   - Сравнение: заявлено минимальные логи без данных diff → изменено — логов нет → проверено по diff.

7. MEDIUM — Отсутствуют тесты (422/413, timeout/LLM stub), хотя заявлены интеграционные/юнит в планах.
   - Evidence: Нет изменений тестовых артефактов; в репозитории только тест-планы .md.
   - Сравнение: заявлено тесты → изменено — нет → проверено по структуре репо.

Потенциальные (POTENTIAL — требует доп. проверки):

P1. POTENTIAL — Несоответствие зависимостей: код использует FastAPI/typing.Protocol, но requirements.txt заявляет, что зависимости не требуются.

P2. POTENTIAL — Совместимость с Python < 3.9 из-за аннотаций dict[str, str].
   - Evidence: TRAINING_PR.diff app/review_service.py:19–22; app/api.py:36–38.

P3. POTENTIAL — Ссылка на app.dependencies.review_service без подтверждения существования модуля в проекте.
   - Evidence: TRAINING_PR.diff app/api.py:30.
