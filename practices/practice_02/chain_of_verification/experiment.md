## Исправленный результат

- Реализовано (подтверждено):
  - POST /api/reviews добавлен; принимает JSON с ключом "diff" без явной схемы и валидации; возвращает {"comment": str}.
  - ReviewService.review формирует свободный промпт и делегирует llm.generate; ответ без структуры OUT-1.
  - Новые внешние зависимости не добавлены.
- Несоответствия и потенциальные проблемы:
  - Нет валидации входа и 422 при отсутствии поля diff; возможен KeyError→500 (нарушение ожидаемой проверки из инкремента 1).
  - Нет ограничения 20 000 символов и кода ответа 413 (API-1).
  - Нет таймаута 10s и контролируемой обработки ошибок LLM (REL-1).
  - Ответ не соответствует OUT-1 (нет summary/risks/checks; только "comment").
  - Отсутствует редактирование/маскирование секретов (SEC-1).
  - Отсутствует наблюдаемость/логирование без чувствительных данных (OBS-1).
  - Отсутствуют тесты, указанные в project_management.md (интеграционные 422/413, юнит/интеграция таймаута и структуры ответа).
  - Аннотации dict[str, str] требуют Python 3.9+: потенциальная несовместимость.
