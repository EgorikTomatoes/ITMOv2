# CryptoExchange Simulator — практика 8

Локальный симулятор криптовалютной биржи с React-интерфейсом и Express API. В рамках практики 8 спроектирован, реализован и протестирован полный клиентский сценарий создания ценового уведомления.

## Основной пользовательский сценарий

Пользователь — начинающий трейдер, который не хочет постоянно следить за котировками. Он открывает раздел «Ценовые уведомления», нажимает «Создать уведомление», выбирает криптовалюту и условие, вводит целевую цену и отправляет форму. После ответа настоящего API диалог закрывается, появляется сообщение об успехе, а созданное уведомление отображается в таблице или мобильной карточке.

Интерфейс отдельно показывает:

- загрузку списка;
- пустой список;
- ошибки загрузки и отправки с возможностью повторить действие;
- процесс отправки формы;
- успешный результат;
- активные, сработавшие и отменённые уведомления.

Во время отправки кнопки и поля блокируются, а синхронный `ref`-флаг не позволяет создать второй запрос двойным кликом или повторным Enter.

## Макет и связь с интерфейсом

Редактируемый макет в Figma: [NOVA — Price Alerts · Practice 08](https://www.figma.com/design/MYYGG1BFymuS5ZmnNBcf98).

Резервный локальный экспорт: [`docs/price-alert-prototype.svg`](docs/price-alert-prototype.svg).

В Figma подготовлены три состояния: desktop-список, desktop-форма создания и мобильный экран. Цвета, отступы и радиусы оформлены локальными переменными `NOVA / Theme`; повторяющиеся кнопки, поля, навигация, строки таблицы, карточки и диалог сделаны компонентами и экземплярами.

Макет охватывает начальное, пустое, заполненное, загружающее, успешное и ошибочное состояния. После проверки AI-макета были изменены:

- таблица заменяется карточками на узком экране;
- ошибка содержит явное действие «Повторить»;
- у формы появились постоянные подписи полей;
- состояние отправки блокирует закрытие и повторный запрос;
- статус передаётся не только цветом, но и текстом.

## Компоненты и дизайн-система

Используется **daisyUI 4** поверх **Tailwind CSS 3**. Готовые компоненты daisyUI: `btn`, `modal`, `input`, `select`, `alert`, `badge`, `card`, `table` и `join`.

Единые цвета заданы темой `nova` в `frontend/tailwind.config.js`. Типографика, базовые цвета, фокус и режим уменьшенного движения находятся в `frontend/src/index.css`. Основной размер текста — не меньше 16 px, подписи — 14 px.

## Установка и запуск

Требуется Node.js 18 или новее.

```bash
npm install
npx playwright install chromium # требуется один раз для дизайн-тестов
npm run dev
```

Интерфейс: `http://localhost:5173`. API: `http://localhost:3001`.

Секреты и переменные окружения для локального запуска не требуются. Данные хранятся в `backend/data/database.json`.

## Команды

```bash
npm run dev          # frontend и backend
npm run build        # production-сборка frontend
npm test             # все серверные и клиентские тесты
npm run test:unit    # тесты бизнес-логики
npm run test:client  # тесты видимого поведения React-интерфейса
npm run test:design  # дизайн-тесты в настоящем Chromium
npm run test:design:update # обновить эталонные скриншоты после согласованного изменения дизайна
npm run reset        # восстановить демонстрационные данные
```

После `npm run reset` перезапустите backend, если он уже работает.

## Клиентские тесты

Тесты находятся в `frontend/src/pages/PriceAlerts.test.jsx`. Vitest запускается в `jsdom`, взаимодействия выполняются через Testing Library и `user-event`. Внешний API подменяется на границе модуля `services/api` тестовыми ответами того же формата, который возвращает backend.

Зафиксированный результат последнего запуска: [`docs/test-results.md`](docs/test-results.md).

Проверяются:

- переход от загрузки к пустому состоянию;
- открытие диалога и закрытие клавишей Escape;
- обязательное поле, отрицательная цена и доступное сообщение об ошибке;
- ошибка API и повторная отправка;
- задержанный ответ и отсутствие второго запроса;
- полный сценарий от ввода цены до новой строки/карточки в интерфейсе;
- ошибка загрузки и восстановление по кнопке «Повторить».

Дополнительно Playwright запускает страницу в настоящем Chromium с фиксированными ответами API. Два screenshot-теста сравнивают весь экран с эталонами для desktop 1440×900 и mobile 390×844. Ещё один тест проверяет высоту основной кнопки и бейджа, основной цвет и контрастную рамку клавиатурного фокуса. Эталоны находятся в `frontend/e2e/__screenshots__`; обновлять их следует только после осознанного изменения макета.

## Доступность и адаптивность

- Все поля связаны с `label`, ошибки объявляются через `role="alert"`.
- Загрузка и отправка объявляются через `role="status"` и `aria-live`.
- Управление доступно с клавиатуры, текущий фокус имеет контрастную рамку.
- Диалог закрывается Escape, но не закрывается во время отправки.
- На ширине меньше `md` таблица превращается в читаемые карточки.
- Поддерживается `prefers-reduced-motion`.

## Использование AI

AI использовался для:

- анализа требований практики и выбора ограниченного основного сценария;
- проектирования состояний макета;
- адаптации интерфейса под daisyUI и мобильный экран;
- составления набора проверок по действиям пользователя;
- написания первой версии клиентских тестов.

Примеры запросов:

1. «Создай макет сценария ценового уведомления: пустое состояние, форма, загрузка, успех и ошибка. Учти мобильный экран и клавиатурную навигацию».
2. «Переиспользуй компоненты daisyUI, сохрани тёмную тему NOVA и покажи статус не только цветом».
3. «Предложи тесты видимого поведения формы, включая задержку API, повторный Enter, ошибку и полный успешный сценарий».

После проверки результата AI вручную были добавлены синхронная защита от повторного запроса, корректные доступные имена, явная повторная попытка, адаптивные карточки и проверки результата именно в интерфейсе.

## Структура

- `frontend/` — React, Vite, Tailwind CSS, daisyUI, Recharts и Lucide;
- `backend/` — Express API, бизнес-логика и JSON-хранилище;
- `tests/` — тесты серверной бизнес-логики;
- `frontend/src/**/*.test.jsx` — клиентские тесты;
- `frontend/e2e/` — Playwright-тесты адаптивности и визуальной регрессии;
- `docs/` — экспорт макета и материалы для демонстрации.
