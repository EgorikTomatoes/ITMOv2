# Отчёт 2. Повторные атаки после исправлений

Дата: 2026-10-30

Краткое резюме: после внесённых исправлений атаки больше не выполняются: SQLi блокированы параметризацией, IDOR и утечки закрыты проверками сессии и ролей, XSS экранирована, опасные действия ассистента проверяются на сервере. Ниже — сверка по каждому кейсу и артефакты.

1) SQL-инъекции
- Результат: запросы с "1 OR 1=1" возвращают 400; assistant/context ограничен и параметризован.
- Доказательства: evidence/after/sqli_profile.json, assistant_context_sqli.json

2) IDOR профилей и заказов
- Результат: /profile?id=2 для Alice возвращает её профиль; /orders без токена — 401; клиенты видят только свои заказы.
- Доказательства: evidence/after/idor_profile_alice_reads_bob.json, orders_list_noauth.json

3) Подмена роли через X-Role
- Результат: /admin/export требует staff-токен, spoof X-Role не работает (403).
- Доказательство: evidence/after/role_spoof_export.json

4) Манипуляция ценой
- Результат: цена заказа игнорирует клиентский price и берётся из каталога.
- Доказательство: evidence/after/price_tampering.json

5) Доступ к чужим файлам
- Результат: клиент ограничен своей директорией и простым именем файла, чужие чеки недоступны.
- Доказательство: evidence/after/files_cross_user.json

6) Утечка логов
- Результат: /debug/logs доступен только staff и значения паролей/токенов редактируются.
- Доказательство: evidence/after/logs_leak.json

7) XSS
- Результат: HTML в отзывах экранируется, теги и скрипты не исполняются.
- Доказательство: evidence/after/reviews_view_xss.json

8) AI-помощник и опасные действия
- Результат: сервер-side guardrails — клиенту запрещены export_profiles/delete_tree и чтение чужих файлов; staff может выполнять разрешённые операции.
- Доказательства: evidence/after/assistant_exec_export_profiles.json, assistant_exec_delete_tree.json, assistant_exec_read_bob.json

9) Принудительная передача опасного решения
- Результат: прямой POST в /assistant/execute с опасным JSON возвращает 403 для клиента, доказывая серверную защиту независимо от поведения модели.

Прогон тестов: make step6, затем make test (см. инструкции). В среде курса требуется Python 3.10+.
