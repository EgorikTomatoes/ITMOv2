# Подтверждения запусков

- `tdd-red.txt` — тесты до появления MCP-сервера, exit code 1.
- `tdd-green.txt` — те же тесты после реализации, exit code 0.
- `skill-run.txt` — повторный запуск проверки публичного seam после загрузки
  skill агентом.
- `mcp-demo.txt` — initialize, успешный tool call и обработка ошибочного входа.
- `opencode-mcp-list.txt` — OpenCode действительно подключил сервер.
- `automatic-check.txt` — результат обязательного runner после всех правок.
- `agent-application.md` — применение `AGENTS.md`, skill, MCP и hook агентом с
  привязкой к воспроизводимым командам и результатам.

Файлы содержат короткие транскрипты, а не только утверждение о наличии
конфигурации. Все команды можно повторить из `practices/practice_04`.
