# Инструкции для AI-агентов

## Назначение проекта

Проект принимает русское предложение, переводит его на английский язык и
преобразует результат в корректное имя переменной для программного кода.
Перевод выполняется локальной моделью через Ollama.

## Область работы

- Работайте только внутри каталога `practices/practice_04`.
- Не изменяйте `presentation.pptx` и файлы других практических работ.
- Не добавляйте внешние Python-зависимости без необходимости: основная программа
  и MCP-сервер используют стандартную библиотеку.

## Структура

- `variable_translator/` — CLI, обращение к Ollama и форматирование имени.
- `mcp_server/` — локальный MCP tool для проверки имени переменной.
- `.agents/skills/tdd/` — выбранный skill и его справочные материалы.
- `tests/` — автоматические тесты без сетевых запросов.
- `scripts/pre-commit-check.sh` — runner автоматической проверки.
- `opencode.json` — подключение локального MCP-сервера.

## Обязательный workflow агента

1. Перед изменениями прочитайте этот файл.
2. Для новой возможности или исправления загрузите
   `.agents/skills/tdd/SKILL.md` и применяйте цикл RED → GREEN через публичный
   интерфейс. Справочные файлы skill читайте по ссылкам из `SKILL.md`.
3. Для проверки предложенного имени переменной вызовите MCP tool
   `identifier-inspector_inspect_identifier`.
4. После любой правки запустите `make check`. Сообщите пользователю команду,
   exit code и итог; не утверждайте, что проверка прошла, без реального запуска.

## Требования к поведению

- Вход: непустое предложение на русском языке.
- Выход: только валидное английское имя переменной.
- Стиль по умолчанию: `snake_case`.
- Поддерживаемые стили: `snake`, `camel`, `pascal`, `constant`.
- Имя не должно начинаться с цифры.
- Ошибки подключения к Ollama должны быть понятными пользователю.
- Ответ модели необходимо очищать и проверять перед выводом.

## Команды

```bash
make setup       # создать локальную модель Ollama
make run         # интерактивный запуск
make test        # Python-тесты
make mcp-demo    # успешный и ошибочный реальные MCP-вызовы
make check       # все линтеры, тесты и сборка расширения
```

## Правила внесения изменений

1. Сохраняйте совместимость с Python 3.9 и новее.
2. Для сетевых тестов подменяйте Ollama на границе системы: тесты не должны
   зависеть от запущенного сервиса или доступа к интернету.
3. При добавлении новой возможности обновляйте `README.md` и тесты.
4. Не выводите рассуждения модели, Markdown или пояснения вместо имени переменной.
