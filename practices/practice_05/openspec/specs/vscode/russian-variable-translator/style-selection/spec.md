# style-selection Specification

## Purpose
Расширение должно запрашивать у пользователя стиль именования переменной при каждом запуске команды перевода, позволяя выбрать snake/camel/pascal/constant перед вводом текста.

## Requirements

### Requirement: Стиль выбирается перед вводом текста
Система SHALL показывать окно выбора стиля (QuickPick) при каждом запуске команды перевода, до появления ввода текста. Предвыбранным вариантом SHALL быть стиль из конфигурации `russianVariableTranslator.style`.

#### Scenario: Пользователь выбирает стиль
- **WHEN** пользователь запускает команду перевода
- **THEN** система показывает список стилей: snake, camel, pascal, constant
- **AND** предвыбранный стиль соответствует конфигурации
- **AND** после выбора система переходит к вводу текста

#### Scenario: Пользователь отменяет выбор
- **WHEN** пользователь закрывает окно выбора стиля (Esc/Cancel)
- **THEN** система SHALL отменить выполнение команды без побочных действий (не открывать ввод текста, не делать запросов, не изменять редактор)

### Requirement: Форматирование соответствует выбранному стилю
Система SHALL применять существующее форматирование идентификатора к ответу Ollama согласно выбранному стилю (snake, camel, pascal, constant) без изменения логики форматирования.

#### Scenario: Применение snake
- **WHEN** выбран snake
- **THEN** результат форматируется snake_case до вставки в редактор

#### Scenario: Применение camel/pascal/constant
- **WHEN** выбран camel, pascal или constant
- **THEN** результат форматируется соответственно camelCase, PascalCase или UPPER_SNAKE_CASE до вставки в редактор
