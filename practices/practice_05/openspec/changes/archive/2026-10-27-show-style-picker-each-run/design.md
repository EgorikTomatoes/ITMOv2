# Design

## Context

Текущая команда делает:
- Читает конфиг russianVariableTranslator (ollamaUrl, model, style)
- Создаёт translator через createOllamaTranslator(fetch, settings)
- Показывает InputBox для ввода русского текста
- Запрашивает Ollama и форматирует ответ в выбранный style
- Вставляет результат в курсор

## Goals / Non-Goals

**Goals:**
- Показ QuickPick со стилем на каждом запуске, до ввода текста
- Предвыбирать style из конфигурации
- При отмене QuickPick — завершать команду без побочных эффектов
- Сохранить существующую логику форматирования и интеграцию с Ollama

**Non-Goals:**
- Нет сохранения последнего выбора между запусками
- Нет новых команд/горячих клавиш для отдельных стилей
- Нет изменений в API Ollama или форматах ответов

## Decisions

1. Интеграция QuickPick в extension.ts перед созданием translator и до InputBox:
   - После выбора стиля — создать translator с override выбранного стиля
   - При cancel — выйти из команды
2. Предвыбор значения QuickPick — из конфигурации `russianVariableTranslator.style`
3. Форматирование остаётся в createOllamaTranslator/formatIdentifier

Альтернативы:
- Вынос форматирования наружу и передача style отдельно — отклонено для минимальности
- Добавление опции askStyleOnEachRun — отклонено согласно требованиям

## Risks / Trade-offs

- Риск: несогласованность UI при отсутствии активного редактора
  → Митигация: поведение уже покрыто — показать ошибку и завершить
- Риск: дублирование значений стилей между QuickPick и типом VariableStyle
  → Митигация: единый источник — VariableStyle и конфиг

## Migration Plan

- Реализация изолирована в extension.ts; обратная совместимость сохраняется (конфиг даёт дефолт выбора)
