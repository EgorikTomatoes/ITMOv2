# Proposal

## Why

Пользователь хочет выбирать стиль именования переменной при каждом запуске команды перевода, вместо заранее фиксированного значения в настройках. Это устранит лишние перезапуски/правки при переключении между snake/camel/pascal/constant и сделает UX предсказуемым и быстрым.

## What Changes

- Показ QuickPick со стилями (snake, camel, pascal, constant) при каждом вызове команды.
- Отмена в QuickPick отменяет команду целиком без побочных действий.
- Сохранение прежнего поведения по умолчанию: предвыбранный пункт QuickPick соответствует текущей конфигурации `russianVariableTranslator.style`.
- Перевод и вставка имени переменной остаются без изменений, кроме выбора стиля.

## Capabilities

### New Capabilities
- `vscode/russian-variable-translator/style-selection`: пользователь при каждом запуске команды может выбрать стиль форматирования результата (snake/camel/pascal/constant) до ввода текста.

### Modified Capabilities


## Impact

- Затронутые файлы: `vscode-extension/src/extension.ts` (точка входа команды), возможно README.
- Не меняются API Ollama и формат запроса; форматирование по-прежнему выполняет существующий код с выбранным стилем.
- Не добавляются новые зависимости.
